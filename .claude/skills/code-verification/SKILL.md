CasualVideo のコード変更を、`Makefile` に定義されたコマンドで検証せよ。**検証コマンドの正本はリポジトリルートの `Makefile`。** 個別の `swift build` / `swift test` を直接叩かず、必ず `make` 経由で実行する。

## 検証手順

リポジトリルートで以下を順に実行する。

1. **ビルド検証**

   ```bash
   make build
   ```

   LocalPackage を iOS シミュレーター向けにビルドする。

2. **テスト検証**

   ```bash
   make test
   ```

   LocalPackage のテストを実行する（カバレッジ計測あり）。

両方をまとめて実行したい場合は `make verify`（`build` → `test`）を使ってよい。

これらの `make` コマンドは実行許可済み（`.claude/settings.json`）なので、**実行ごとに確認を求めず実行してよい。**

## 失敗時の対応

- **ビルド失敗**: エラーメッセージから原因（型エラー・依存方向違反・import 漏れなど）を特定し、修正してから再度 `make build` を実行する。アーキテクチャ起因の疑いがあれば `docs/architecture.md` を参照する。
- **テスト失敗**: 失敗したテスト名と期待値・実値を確認する。プロダクトコードの不具合かテストの誤りかを切り分けて修正し、再実行する。
- 修正後は失敗した段階から再検証し、最終的に `make build` と `make test` の両方が通る状態にする。

## 完了前に必ず行うこと

- `make build` と `make test`（または `make verify`）の両方が成功していることを確認する。
- 実行したコマンドと結果（成功 / 失敗→対応内容）、テスト件数を簡潔に報告する。失敗を成功と偽らない。
