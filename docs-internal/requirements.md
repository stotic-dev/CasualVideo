# 要件定義書

CasualVideo の要件を定義する。実装・レビュー時はこの要件をスコープの基準とすること。

## 1. 概要

### 1.1 コンセプト

iOS の写真ライブラリ（標準アルバム / iCloud）にある動画を、アプリから **ラフに流し見** するための個人用動画プレイヤー。マルチタスクしながら思い出を振り返る体験を中心に据える。

一言で言えば「**自分専用の、アルバム動画版の"ながら見"プレイヤー**」。

### 1.2 ターゲットユーザー

- 開発者本人（単一ユーザー）。
- 不特定多数への配信や共有は想定しない。アカウント・ログイン機構は不要。

### 1.3 体験のキーワード

- **ラフ**: 厳密な操作より「とりあえず流す」を優先する。
- **ながら見 / マルチタスク**: 他アプリを操作しながら動画を流し続けられる（PIP）。
- **振り返り**: 過去の動画を連続・シャッフルで眺める。

## 2. スコープ

### 2.1 MVP（最優先）

最優先体験は **PIP バックグラウンド再生**。これを軸に、以下を MVP の範囲とする。

| # | 機能 | 概要 |
|---|------|------|
| F-1 | 写真ライブラリの動画一覧 | PhotoKit 経由でアルバム / iCloud の動画を一覧表示する。 |
| F-2 | 動画再生 | 一覧から選んだ動画を再生する。 |
| F-3 | PIP バックグラウンド再生 | Picture in Picture で、他アプリ操作中・バックグラウンドでも再生を継続する。**MVP の中核**。 |
| F-4 | プレイリスト連続再生 | 複数動画を途切れず連続再生する。 |
| F-5 | シャッフル / リピート | プレイリストのシャッフル再生・リピート再生。 |
| F-6 | プレイリスト編成 | 手動で動画を選んで追加 / 既存アルバム単位でまとめる / 全動画をそのまま再生。 |
| F-7 | 音声ミュート切り替え | 再生中に音声のミュート / 音ありをトグルで切り替える。 |
| F-8 | プレイリストの永続化 | 作成したプレイリスト・設定を端末内に保存する（SwiftData）。 |

### 2.2 将来拡張（MVP 対象外）

- 期間・日付による自動プレイリスト生成（「先月」「去年の今頃」など）。
- iCloud によるプレイリストのマルチデバイス同期。
- 再生速度の変更、フィルター・編集などの加工機能。
- お気に入り / タグ付け、検索。

### 2.3 非対象（スコープ外）

- 動画の撮影・編集・書き出し。
- SNS 共有・外部送信。
- 複数ユーザー / アカウント管理。

## 3. 機能要件

### 3.1 写真ライブラリ連携（F-1, F-2）

- PhotoKit を用いて、写真ライブラリ内の **動画アセット** を取得・一覧表示する。
- iCloud 上にあり端末にダウンロードされていない動画も扱う（必要時にダウンロードして再生）。
- 写真ライブラリへのアクセス許可をリクエストし、未許可・拒否時のフォールバック表示を行う。
- 一覧はサムネイル + 再生時間などのメタ情報で表示する。

### 3.2 プレイリスト（F-4, F-5, F-6, F-8）

- プレイリストの作成方法は次の3通りをサポートする:
  1. **手動選択**: 動画を個別に選んで追加する。
  2. **アルバム単位**: 既存アルバムをまとめてプレイリスト化する。
  3. **全動画**: ライブラリ全体をそのまま再生対象とする。
- 再生モード: **連続再生 / シャッフル再生 / リピート再生**。
- プレイリストと再生設定は端末内（SwiftData）に永続化する。

### 3.3 再生・PIP（F-3, F-7）

- 通常の全画面再生に加え、**PIP（Picture in Picture）** に対応する。
- PIP 状態で他アプリへ遷移・バックグラウンドへ移行しても再生を継続する。
- バックグラウンド再生のための Audio Session / Background Modes 設定を行う。
- 再生中に **音声ミュート / 音あり** をトグルで切り替えられる（初期値は実装時に決定）。
- プレイリスト再生時は、1動画の再生終了で次の動画へ自動遷移する。

## 4. 非機能要件

- **プラットフォーム**: iOS 26.0 以上（`docs-internal/architecture.md` / `CLAUDE.md` 準拠）。
- **アーキテクチャ**: 既存のレイヤード構成（App / Features / Core / Infra）に従う。PhotoKit・SwiftData への I/O は `Infra` に閉じ、`Repository` 経由でアクセスする。
- **テスト**: Swift Testing でロジック層（Core / Features の Store）を検証する（`docs-internal/testing.md` 準拠）。
- **プライバシー**: 写真ライブラリアクセスの用途を `Info.plist`（`NSPhotoLibraryUsageDescription` 等）に明記する。データは端末内に留め、外部送信しない。
- **パフォーマンス**: 大量動画でも一覧スクロールが滑らかに動くよう、サムネイル取得を遅延・非同期で行う。

## 5. 技術的な前提・論点

- **写真ライブラリアクセス**: PhotoKit（`PHAsset` / `PHImageManager` / `PHCachingImageManager`）。iCloud 動画は `PHVideoRequestOptions` でネットワークアクセスを許可。
- **再生エンジン**: AVKit / AVFoundation（`AVPlayer`, `AVPlayerLayer`, `AVPictureInPictureController`）。
- **バックグラウンド再生**: `AVAudioSession` のカテゴリ設定、Background Modes（Audio, AirPlay, PiP）を有効化。
- **永続化**: SwiftData（端末内）。プレイリスト本体は動画アセットの **識別子（`localIdentifier`）参照** で保持し、動画実体は写真ライブラリ側に委ねる。

### 5.1 未確定の論点（実装時に決める）

- 音声ミュートの初期値（ミュート開始 or 音あり開始）。
- プレイリスト内での動画の並び順管理（手動並べ替えの要否）。
- アルバム単位プレイリストの「動的（アルバム追従）/ 静的（作成時点で固定）」の扱い。
- 写真ライブラリ側で動画が削除された場合のプレイリスト整合性の扱い。

## 6. 画面構成（たたき台）

- **ライブラリ画面**: 写真ライブラリの動画一覧 / アルバム一覧。再生・プレイリスト追加の起点。
- **プレイリスト一覧画面**: 作成済みプレイリストの一覧と管理。
- **プレイリスト詳細画面**: 内包する動画一覧と再生開始（連続 / シャッフル / リピート）。
- **再生画面**: 全画面再生。PIP 起動、ミュート切り替え、次/前送り、再生モード切り替え。

> 本章はあくまで初期案。詳細な画面遷移・UI は別途設計フェーズで詰める。
